# ONG Campanha do Agasalho

Projeto desenvolvido como atividade acadêmica para uma ONG fictícia de campanha do agasalho.

## Sobre o projeto

A aplicação apresenta informações sobre a campanha, seus objetivos e projetos, além de permitir o cadastro de pessoas interessadas em participar.

O projeto foi desenvolvido utilizando:

- HTML
- CSS
- JavaScript
- JavaScript ES6 Modules
- localStorage
- Hash Navigation

## Estrutura do projeto

- `HTML/` — arquivos HTML
- `CSS/` — arquivos de estilos
- `JS/` — arquivos JavaScript
- `JS/Modules/` — módulos JavaScript
- `images/` — imagens utilizadas no projeto

## GitFlow

O desenvolvimento utiliza uma estrutura de branches baseada no GitFlow:

- `main` — versão estável do projeto
- `develop` — branch de desenvolvimento
- `feature/` — desenvolvimento de novas funcionalidades
- `hotfix/` — correções urgentes na versão estável

## Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, utilizando CSS Grid, Flexbox e Media Queries.

## Controle de versão

O projeto utiliza GitFlow para organizar o desenvolvimento por meio das branches main, develop, feature e hotfix.
